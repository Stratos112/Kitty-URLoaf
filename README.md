# Kitty-URLoaf
Browser Plugin that adds an animated/interactive kitty. 

## Roadmap

1. Slow down the breathing/head-bob animations for a more natural feel.
2. Bundle the current animation state as "idle awake," and build a mirrored "sleeping idle" state: head down on her paws, eyes closed, with an occasional head-raise. Two named idle states total.
3. Dynamic margins at the three anchor locations (A: TabsToolbar, C: nav-bar, D: sidebar strip) — widen the area's margin when Pants is present there, restore it to normal when she's not.
4. Let the user pick the exact sub-position within A/C/D during setup, not just which location — placement should account for whatever other toolbar widgets/buttons the user already has, so we need a way for them to indicate free space.
5. New sidebar button + content area for expanded interactions — a panel where Pants can go do more things (cat tree, water bowl, etc.). Opening the panel sends her there; closing it, she leaves.
6. Mouse-reactive interactivity outside idle animations — e.g. eyes tracking the cursor, batting at it when it gets close.
